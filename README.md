# おやすみ手続きナビ

相続の初期整理を、ひとつずつ。大切な方を亡くされた直後に、今日やること・期限・必要書類・公的制度・相談先を整理する日本向けMVPです。

## できること

- 死亡日、最後の住所の市区町村、相続の状況を入力
- 入力内容に合わせた初期整理結果の表示
- 手続きのタイムラインと期限の目安
- 必要書類と、国の機関による公式案内へのリンク
- 自治体ごとの担当課の目安と、`lg.jp` に限定した検索ボタン
- 用語の入手方法を表示する小窓
- 状況整理メモのコピー・印刷

このMVPはAPI、ログイン、DB、決済を使わず、入力内容をブラウザ内のReact stateだけで扱います。画面を閉じると入力内容は保存されません。

## ローカルで動かす

Node.js 22以上を用意して、次を実行します。

```bash
npm ci
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

本番ビルドの確認：

```bash
npm run build
npm run start
```

## GitHubで使うとき

このフォルダをそのままGitHubリポジトリへアップロードできます。`.env`、`node_modules`、`.next`、`dist`、Wranglerのローカル状態は `.gitignore` で除外しています。

GitHub Actionsでは、pushとPull Requestごとに `npm ci` と本番ビルドを確認します。`main` へのpush時は、クライアントだけで完結する静的版も作成してGitHub Pagesへ自動デプロイします。公開URLは `https://megaminohakoniwa.github.io/Shion/` です。通常のプレビュー用にはVinext/Cloudflare Workers向けのビルド構成も残しています。

## 公的情報について

結果画面の外部リンクは、法務省・法務局・裁判所・国税庁・厚生労働省・日本年金機構などの公的機関を中心に設定しています。市区町村のページは自治体ごとに異なるため、入力した自治体名と手続き名を使って `lg.jp` の公式ページを検索します。

表示内容は一般的な情報の整理例であり、法律・税務上の判断や個別の助言ではありません。期限の起算日や必要書類は状況によって変わるため、重要な判断の前に公的窓口または専門家へ確認してください。
