# おやすみ手続きナビ

相続の初期整理を、ひとつずつ。大切な方を亡くされた直後に、今日やること・期限・必要書類・公的制度・相談先を整理する日本向けMVPです。

## できること

- 死亡日、最後の住所の市区町村、相続の状況を入力
- 入力内容に合わせた初期整理結果の表示
- 手続きのタイムラインと期限の目安
- 必要書類と、国の機関による公式案内へのリンク
- 自治体ごとの担当課の目安と、`lg.jp` に限定した検索ボタン
- 用語の入手方法を表示する小窓
- 状況整理メモのコピー・印刷
- 自由入力から手がかりを確認するクエスト型の進行
- 「あなたの現在地」、確認リスト、制度カード、一般的な手続きタイムライン
- 前回の続きから再開できる端末内進捗保存・初期化
- 事業者向けデモ管理画面（相談者一覧・絞り込み・詳細・対応メモ）

このMVPはAPI、ログイン、DB、決済を使わず、一般利用者向けの入力・進捗・クエスト・追加メモを `localStorage`（キー：`oyasumi-journey-demo-v1`）にのみ保存します。サーバーや外部サービスへの送信はありません。画面上の「このデモの入力・進捗を初期化」から削除できます。

事業者向け管理画面は営業・ユーザーテスト用のデモです。表示される相談者情報はダミーデータで、実データ保存・認証・外部送信機能はありません。一般ユーザーの結果画面にある共有ボタンも、デモ用の案内を表示するだけです。

## ローカルで動かす

Node.js 22以上を用意して、次を実行します。

```bash
npm ci
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

本番ビルドの確認：

```bash
npm run build
npm run start
```

## GitHubで使うとき

このフォルダをそのままGitHubリポジトリへアップロードできます。`.env`、`node_modules`、`.next`、`dist`、Wranglerのローカル状態は `.gitignore` で除外しています。

GitHub Actionsでは、pushとPull Requestごとに依存関係のインストールと本番ビルドを確認します。`main` へのpush時は、クライアントだけで完結する静的版も作成してGitHub Pagesへ自動デプロイします。公開URLは `https://megaminohakoniwa.github.io/mimi/` です。通常のプレビュー用にはVinext/Cloudflare Workers向けのビルド構成も残しています。

## 公的情報について

結果画面の外部リンクは、法務省・法務局・裁判所・国税庁・厚生労働省・日本年金機構などの公的機関を中心に設定しています。市区町村のページは自治体ごとに異なるため、入力した自治体名と手続き名を使って `lg.jp` の公式ページを検索します。

表示内容は一般的な情報の整理例であり、法律・税務上の判断や個別の助言ではありません。期限の起算日や必要書類は状況によって変わるため、重要な判断の前に公的窓口または専門家へ確認してください。

## 将来のAPI接続ポイント

現在の自由入力の手がかり整理は、`app/page.tsx` の `extractFacts` を使ったキーワードベースのデモ実装です。将来OpenAI APIなどを接続する場合は、この関数をサーバー側の要約・分類処理へ置き換え、返却値を `JourneyFact` の確認待ちデータとして表示します。クエストの完了・制度の確認状態は、同ファイルの `JourneyState` を `users`・`consultations`・`status` などのDBモデルへ分離し、認証と権限確認を加えて保存する想定です。現時点では法的判断、相続人の確定、期限の確定、税額計算、専門家への自動送信は実装していません。
